# VocabBuilder

VocabBuilder is a responsive web application for learning English vocabulary. Users can create and manage their own dictionary, discover recommended words, and improve memorization through interactive training sessions.

![VocabBuilder](./assets/preview.png)

## Demo

- **Live Demo:** https://vocab-builder-indol-one.vercel.app/
- **Backend API:** https://vocab-builder-backend.p.goit.global/api

---

## Features

### Authentication

- User registration
- User login/logout
- Protected routes
- Persistent authentication

### Dictionary

- View personal vocabulary
- Add new words
- Edit existing words
- Delete words
- Search by keyword
- Filter by category
- Learning progress for each word

### Recommendations

- Browse recommended vocabulary
- Search recommended words
- Filter by category
- Add words to personal dictionary

### Training

- Random learning sessions
- Translation exercises
- Progress tracking
- Results summary after each session

## Installation

```bash

cd vocab-builder

npm install

npm run dev
```
